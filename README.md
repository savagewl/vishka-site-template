# ВЫШКА — фестиваль плакатной типографики

Лендинг вымышленного фестиваля «ВЫШКА / ШУМ» в стилистике брутализма. Вёрстка макета из Figma (шаблон S10 · Brutalism) один к одному на десктопе, плюс собственная адаптивная версия для планшета и телефона.

## Стек

- React 19 + TypeScript
- Vite
- CSS Modules, без UI-библиотек
- Шрифты подключены локально через `@fontsource`: Advent Pro, Geist Mono, Rubik, Montserrat
- [Lenis](https://github.com/darkroomengineering/lenis) — плавный скролл

## Запуск

```bash
npm install
npm run dev      # dev-сервер
npm run build    # проверка типов и production-сборка в dist/
npm run preview  # просмотр собранной версии
npm run lint     # oxlint
```

## Структура

```
src/
├── main.tsx                 точка входа
├── App.tsx                  порядок секций страницы
├── styles/
│   ├── fonts.css            подключение начертаний
│   ├── tokens.css           цвета, шрифты, отступы (CSS-переменные)
│   └── base.css             сброс и глобальные стили
├── data/                    контент: навигация, программа, спикеры, билеты, FAQ, галерея
├── components/
│   ├── ui/                  Tag, SectionHeader, Modal
│   ├── popups/              попапы регистрации и покупки билета (заглушки) + контекст для их открытия
│   └── icons/               CheckIcon
├── hooks/                   useSmoothScroll (Lenis), useScrollProgress (прогресс скролла в CSS-переменную)
├── sections/                Header, Hero, Parallax, Manifesto, Program, Speakers, Tickets, Faq, Footer
└── assets/
    ├── images/              фото (webp)
    └── shapes/              SVG: рваные края, полигоны и маска здания для hero
```

Каждая секция лежит в своей папке вместе со стилями (`Section.tsx` + `Section.module.css`). Весь текстовый контент вынесен в `src/data`, поэтому шаблон можно перенастроить под другое событие, не трогая вёрстку.

## Детали реализации

- **Hero** собран слоями, как в макете: полигоны, слово «ВЫШКА», чёрно-белое фото здания, обрезанное по силуэту, и поверх него фиолетовая заливка того же силуэта в режиме `mix-blend-mode: color-dodge`. Она красит фото в лавандовый и подсвечивает буквы под вырезом. Координаты заданы в «пикселях макета» через переменную `--u`, поэтому композиция масштабируется целиком под ширину экрана.
- **Первый экран:** вся композиция hero масштабируется одним коэффициентом по ширине, поэтому здание перекрывает «ВЫШКА» ровно как в макете. Высота hero ограничена первым экраном: лишнее срезается снизу, а плашка статистики прижимается к низу окна.
- **Эффект «заката»:** при прокрутке слово «ВЫШКА» и фиолетовые полигоны опускаются и уходят за здание, заголовок гаснет, при обратной прокрутке всё «восходит». Прогресс скролла пишет в CSS-переменную хук `useScrollProgress`, анимацию делает CSS (transform), React при скролле не перерисовывается. При `prefers-reduced-motion` эффект выключен.
- **Параллакс слоями** между hero и манифестом (по мотивам Osmo «Parallax Image Layers»): наборная касса в дуотоне, рваная бумага, заголовок «Типографский бунт» и передний рваный край двигаются с разной скоростью (`--speed` у каждого слоя), заголовок уходит за передний край. Прогресс считает тот же `useScrollProgress` в режиме `from: 'screen'`.
- **Плавный скролл** на Lenis (`autoRaf`, как в сетапе Osmo). Переходы по пунктам меню тоже плавные; позицию якоря хук считает сам, потому что встроенные `anchors` Lenis промахиваются на секциях с CSS `zoom`.
- **Попапы-заглушки:** «Регистрация» (шапка и CTA в подвале) и «Купить билет» (карточки тарифов). Сделаны на нативном `<dialog>`: фокус внутри, закрытие по Esc, крестику и клику по фону, страница под попапом не скроллится. Формы проверяют обязательные поля и показывают экран «готово», но данные никуда не отправляют. В покупке билета есть выбор количества и пересчёт суммы.
- **Широкие экраны:** секции ниже hero пропорционально увеличиваются (`--zoom`, ступенями от 1280 px), на 1088 — макет 1:1.
- **На широких экранах** фоны, рваные края и скосы тянутся на всю ширину, а контент секций держится в колонке 1088px по центру (переменная `--pad-x`). Hero масштабируется целиком, шапка выровнена по его заголовку.
- **Рваные края и полигоны** выгружены из Figma как векторы. Косые переходы между секциями сделаны через `clip-path`.
- **Ступенчатый CTA** в подвале — одна плашка с `clip-path`, которая учитывает и вырезы, и внутреннюю обводку макета.
- **FAQ** построен на нативных `<details>`: все вопросы открыты, как в макете, и сворачиваются по клику.
- Фото в манифесте и галерее обработаны тем же фирменным дуотоном, что и hero.
